Fast search

Find files and folder sizes in buckets that are too large for normal browsing.

S3 does not provide native folder sizes or instant full-bucket search. S3Panel builds a metadata manifest and index so you can search object names, keys, sizes, dates, and cached folder totals quickly.

Security

Your buckets stay with your provider.

S3Panel is a control plane. It stores account data, encrypted connection metadata, audit logs, and object metadata needed for search and folder statistics. It does not host customer bucket contents.

  • Use least-privilege S3/R2 credentials per connection.
  • Object downloads use temporary presigned URLs.
  • macOS sessions are stored in Keychain where supported.
  • Read-only credentials can browse and search without destructive operations.
