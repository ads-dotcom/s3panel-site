# S3Panel Site

Marketing, legal, support, pricing, and download pages for `s3panel.com`.

This project is based on the purchased ThemeForest NextSaaS `ai-saas-software` Next.js template and is adapted for S3Panel's S3-compatible storage and Cloudflare R2 management product.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The site uses `output: "export"` and writes static files to `out/` for Cloudflare Pages.
